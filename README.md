# Bingzhen Li's Page

A lightweight, no-build personal site ready for GitHub Pages.

## Publish with GitHub Pages

1. Create an empty GitHub repository, for example `bingzhen-li-page`.
2. Upload the contents of this folder to the repository root (not the folder itself).
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the public address after the site is published.

## Customize

- Replace the email address in `index.html`.
- Add new post rows in the `#post-list` section.
- Change colors at the top of `style.css`.

The search button filters all posts using their hidden `data-search` keywords.
